# Exploratory Data Analysis (EDA) using Python

## Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a dataset using Python in Google Colab. The goal is to understand the dataset by cleaning the data, checking missing values, finding duplicates, generating summary statistics, and creating visualizations. EDA helps identify patterns, trends, outliers, and relationships between variables before applying machine learning models.

## Objectives

* Load and explore the dataset.
* Check dataset structure and data types.
* Identify and handle missing values.
* Detect duplicate records.
* Generate summary statistics.
* Visualize data using charts and graphs.
* Analyze relationships between features using correlation.

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## EDA Steps Performed

1. Imported required Python libraries.
2. Loaded the dataset into a Pandas DataFrame.
3. Displayed the first few rows of the dataset.
4. Checked dataset information and data types.
5. Calculated summary statistics.
6. Identified missing values and duplicates.
7. Created visualizations such as histogram, bar chart, box plot, scatter plot, and heatmap.
8. Performed correlation analysis between numerical features.

## Output

The project provides insights into the dataset through statistical analysis and visualizations. It helps prepare clean and meaningful data for further analysis and machine learning.
